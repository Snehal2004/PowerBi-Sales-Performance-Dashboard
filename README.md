# 📊 Sales Performance Dashboard – Power BI

## 📌 Project Overview
This project focuses on analyzing sales data and creating an interactive dashboard using Microsoft Power BI. The dashboard helps understand sales performance, revenue, profitability, and customer behaviour.

## 🛠️ Tools Used
- Microsoft Power BI
- Microsoft Excel
- Power BI Q&A

## 📂 Dataset
The dataset contains sales information, including:
- Order Date
- Region and Country
- Sales Channel
- Customer Type
- Product Category and Product
- Units Sold
- Revenue and Gross Profit
- Discounts and Gross Margin

## 🎯 Project Objectives
- Analyze overall sales performance.
- Identify top-performing products and regions.
- Understand customer purchasing behaviour.
- Analyze revenue and profitability.
- Present business insights through interactive visualizations.

## 📁 Project Files
- `Sales_Data.xlsx` – Sales dataset
- `Sales_Performance_Dashboard.pbix` – Power BI dashboard
